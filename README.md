## 1. نظرة عامة والمواصفات المدعومة

تم تصميم نظام الطباعة في تطبيق **الحليم** ليتوافق بدقة مع معايير طباعة الإيصالات الحرارية عبر بروتوكولات **ESC/POS** القياسية ونوافذ الطباعة الحديثة (CSS Paged Media).

### 📏 المقاسات القياسية المدعومة:
* **مقاس 80 مم (80mm / 3-inch):**
  - **عرض الطباعة الفعلي:** `72mm` (نحو 576 نقطة/Dot).
  - **الاستخدام الأساسي:** فواتير الحسابات، بوالص الشحن، وإيصالات التسليم المفصلة.
  - **الأبعاد التنسيقية:** `width: 80mm; max-width: 80mm;`.
* **مقاس 58 مم (58mm / 2-inch):**
  - **عرض الطباعة الفعلي:** `48mm` (نحو 384 نقطة/Dot).
  - **الاستخدام الأساسي:** الطابعات المحمولة للبلوتوث والمندوبين الميدانيين وماكينات POS المدمجة.
  - **الأبعاد التنسيقية:** `width: 58mm; max-width: 58mm;`.

### 🏭 أشهر العلامات التجارية المتوافقة:
* **Xprinter** (XP-58, XP-80, XP-N160, XP-Q90EC, XP-D200N).
* **Epson POS** (TM-T20, TM-T88, TM-m30).
* **Bixolon** (SRP-330, SRP-350, SPP-R200/R300).
* **Sunmi / POSBANK / Milestone / Netum / ZKTeco / GOOJPRT / Rongta**.

## 2. متطلبات برامج التشغيل والمحركات (Drivers)

### أ. نظام Windows:
1. **تثبيت التعريف المعتمد:**
   - قم بتحميل وتثبيت ملف التعريف الرسمي من الشركة المصنعة (مثل **Xprinter Driver V7.77** أو **Epson Advanced Printer Driver APD**).
   - اختر منفذ التوصيل المناسب (**USB001 / USB002** أو **Virtual COM Port**).
2. **ضبط خصائص الطابعة الافتراضية (Printer Properties):**
   - افتح لوحة التحكم `Control Panel` ⬅️ `Devices and Printers` ⬅️ انقر بزر الفأرة الأيمن على الطابعة واختر `Printing Preferences`.
   - **نوع وحجم الورق (Paper Size):**
     - لطابعة 80mm: حدد `80mm x Receipt` أو `80mm x 297mm`.
     - لطابعة 58mm: حدد `58mm x Receipt` أو `58mm x 210mm`.
   - **القص التلقائي (Auto Cutter):** فعّل خيار `Cut at end of document / Cut Receipt`.
   - **درجة وضوح الحبر والحرارة (Density / Darkness):** اختر القيمة المتوسطة أو العالية لضمان قراءة الباركود وQR Code بدقة.

### ب. نظام macOS:
1. قم بتوصيل الطابعة عبر منفذ USB.
2. توجه إلى `System Settings` ⬅️ `Printers & Scanners`.
3. انقر على `Add Printer` (+).
4. في خانة **Use / Driver**:
   - إذا كان هناك تعريف من الشركة (مثل CUPS Driver) قم باختياره.
   - أو اختر تعريف **Generic ESC/P POS Printer** أو **Raw Queue**.
5. قم بإنشاء حجم مخصص للصفحة `Custom Paper Size` بأبعاد:
   - 80 مم: العرض `80mm` والارتفاع `300mm` مع هوامش `0mm`.
   - 58 مم: العرض `58mm` والارتفاع `250mm` مع هوامش `0mm`.

### ج. أنظمة Linux / Ubuntu:
1. تثبيت حزمة CUPS:
   ```bash
   sudo apt-get update && sudo apt-get install cups cups-client
   ```
2. إضافة الطابعة إلى قائمة الأجهزة المحلية عبر المتصفح: `http://localhost:631/admin`.
3. اختر نوع الطابعة وطبق ملف PPD المخصص لطابعات POS (مثل `POS-80.ppd` أو `Generic-Text-Only`).

### د. أجهزة Android و iOS:
* **عبر متصفح Chrome/Safari:**
  - تدعم الطباعة عبر خدمة الطباعة السحابية أو خدمات النظام المباشرة (Android Print Service / AirPrint للطابعات الداعمة لـ IP).
* **طابعات البلوتوث المباشرة (ESC/POS over Bluetooth):**
  - يتم التعرف التلقائي على الطابعة بمجرد الاقتران من خلال نظام الـ Web Bluetooth أو تطبيق الخدمة المساعد.

## 3. توصيات وإعدادات المتصفح للطباعة المباشرة

للحصول على إيصال حراري متناسق بدون أي زوائد أو هوامش فارغة، يُرجى تطبيق الإعدادات التالية داخل شاشة الطباعة الخاصة بالمتصفح (`Ctrl + P`):

### أ. إعدادات Google Chrome & Microsoft Edge:
| الخيار (Setting) | القيمة الموصى بها | السبب والهدف |
| :--- | :--- | :--- |
| **الوجهة (Destination)** | اختر الطابعة الحرارية المعرفة (مثال: `POS-80`) | ضمان توجيه الأمر للمنفذ الصحيح |
| **حجم الورق (Paper size)** | `80mm` أو `58mm` (أو `Roll Paper`) | تفادي تقليص الفاتورة وتمدد المسافات |
| **الهوامش (Margins)** | **مخصصة (Custom: 0) أو بلا (None)** | إتاحة كامل مساحة الرول للنصوص والجداول |
| **المقياس (Scale)** | **افتراضي (Default) أو 100%** | منع تشويه حجم الخطوط وشفرة الباركود |
| **الرؤوس والتذييلات (Headers and footers)** | **غير مفعل (Unchecked / معطل)** | منع طباعة رابط الصفحة وتاريخ المتصفح في أعلى وأسفل الإيصال |
| **رسومات الخلفية (Background graphics)** | **مفعل (Checked / نشط)** | لظهور الإطارات والألوان الخلفية للرؤوس والإجماليات |

---

### ب. تفعيل وضع الطباعة الصامتة (Kiosk Printing)

للكاشير ونقاط البيع السريعة، يمكن تشغيل متصفح **Chrome** أو **Edge** في وضع "الطباعة الفورية التلقائية" حيث يُطبع الإيصال فوراً بمجرد الضغط على زر الطباعة داخل التطبيق بدون ظهور شاشة المعاينة:

#### طريقة تفعيل وضع الكشك الصامت على Windows:
1. انقر بزر الفأرة الأيمن على اختصار متصفح **Google Chrome** على سطح المكتب.
2. اختر **خصائص (Properties)** ⬅️ تبويب **اختصار (Shortcut)**.
3. في حقل **الهدف (Target)**، أضف الأمر التالي في نهاية السطر بعد المسافة:
   ```text
   --kiosk-printing
   ```
   *مثال على الحقل كاملاً:*
   ```text
   "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing
   ```
4. انقر على **تطبيق (Apply)** ثم **موافق (OK)**.
5. الآن، عند النقر على أمر الطباعة داخل نظام الحليم، ستتم الطباعة في ثانية واحدة مباشرة عبر الطابعة الافتراضية.

## 4. طرق التوصيل والربط واختبار الاتصال

### أولاً: التوصيل عبر كابل USB

1. **الربط المادي:**
   - صل كابل USB المرفق بالطابعة بأحد منافذ الكمبيوتر مباشرة (يُفضل تجنب الـ USB Hub غير المزود بمحول كهربائي).
   - صل كابل الكهرباء وتأكد من إضاءة مؤشر **Power** باللون الأخضر/الأزرق.
2. **فحص التعرف على الجهاز (Windows Device Manager):**
   - افتح `Device Manager` ⬅️ تحقق من ظهور الطابعة تحت قسم `Printers` أو `Ports (COM & LPT)` أو `Universal Serial Bus controllers`.
3. **اختبار التغذية والطباعة الذاتية (Hardware Self-Test):**
   - أطفئ مفتاح تشغيل الطابعة (Power OFF).
   - اضغط مع الاستمرار على زر **تغذية الورق (FEED)**.
   - أعد تشغيل مفتاح الطاقة (Power ON) مع الاستمرار بالضغط على زر FEED لمدة 3 ثوانٍ ثم اتركه.
   - ستقوم الطابعة بطباعة تذكرة تجريبية توضح سرعة النقل (Baud Rate)، الكثافة، وإصدار الفيرموير الداخلي.
4. **طباعة صفحة اختبار من نظام التشغيل:**
   - من إعدادات الطابعات، انقر على `Print Test Page` للتأكد من وصول الأمر بسلاسة.

---

### ثانياً: التوصيل اللاسلكي عبر البلوتوث (Bluetooth)

1. **تشغيل وضع الاقتران:**
   - شغّل الطابعة الحرارية وتأكد من وجود رول الورق بشكل صحيح.
2. **الاقتران من جهاز الكمبيوتر أو التابلت:**
   - افتح إعدادات البلوتوث `Bluetooth & devices` ⬅️ انقر على `Add device`.
   - اختر اسم الطابعة من القائمة (يظهر غالباً بالأسماء: `POS-58`, `MTP-II`, `RPP02N`, `Printer001`, `InnerPrinter`).
   - أدخل رمز الحماية والتوصيل الافتراضي (PIN Code):
     - الرمز الأكثر شيوعاً: `0000` أو `1234` أو `1111`.
3. **تعيين المنفذ التسلسلي الظاهري (Virtual Outbound COM Port):**
   - في أنظمة Windows: ادخل إلى `More Bluetooth settings` ⬅️ تبويب `COM Ports`.
   - لاحظ رقم المنفذ الصادر (مثال: `COM3` أو `COM4`).
   - في تعريف الطابعة الافتراضية، اختر هذا المنفذ في خانة `Ports`.
4. **اختبار طباعة الإيصال:**
   - افتح تطبيق الحليم، ادخل على أي فاتورة من فواتير الطلبات، وانقر على زر **طباعة حراري 80mm / 58mm**.

## 5. جدول استكشاف الأخطاء وإصلاحها (Troubleshooting & FAQs)

| المشكلة | السبب المحتمل | الحل المقترح |
| :--- | :--- | :--- |
| **خروج الورق أبيض تماماً بدون أي طباعة** | رول الورق مركب بالمقلوب | اقلب بكرة الورق بحيث يكون الوجه الحراري اللامع موجهاً نحو رأس الطباعة الحراري. |
| **تقطيع أو طباعة الحروف العربية بشكل معكوس أو علامات استفهام** | عدم تفعيل محرك الخطوط أو استخدام وضع Raw غير مدعوم | اطبع عبر معاينة المتصفح الاعتيادية في التطبيق حيث يتم تصيير النصوص العربية كـ Vector Graphics نقية بنسبة 100%. |
| **خروج مسافة بيضاء طويلة جداً بعد الفاتورة** | ضبط حجم الصفحة على A4 بدلاً من Receipt | من شاشة إعدادات الطباعة، غيّر حجم الورق (Paper Size) إلى `Roll Paper 80x297mm` أو `58mm Roll`. |
| **عدم استجابة الطابعة نهائياً لأمر الطباعة** | تعليق بفر الطابعة أو خطأ في المنفذ | 1. أعد تشغيل الطابعة.<br>2. افتح قائمة انتظار الطباعة (Print Queue) وقم بإلغاء كافة الأوامر العالقة.<br>3. تأكد من ثبات كابل USB. |
| **ظهور الباركود أو الـ QR Code باهتاً وصعب القراءة** | رأس الطباعة الحراري متسخ أو إعداد الكثافة منخفض | نظف رأس الطباعة بقطعة قطن مبللة بكحول إيزوبروبيل، وارفع قيمة `Print Density` في إعدادات المحرك. |
| **القصاصة التلقائية (Cutter) تقطع الفاتورة في المنتصف** | ضبط أبعاد الإيصال أقصر من المحتوى الفعلي | في إعدادات Driver اختر `Doc Feed: After Print` وعين خيار `Page Cut` في نهاية المستند. |
